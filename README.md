# Sistema de Control de Medicación

Proyecto de Programación II – Ingeniería de Software, UDLA.

## Descripción
Sistema desarrollado en Java para gestionar medicamentos, tratamientos y seguimiento de la adherencia en adultos mayores.

## Módulos
1. Pacientes y cuidadores – Gabriela
2. Medicamentos y advertencias – María Emilia
3. Tratamientos y esquemas de dosificación – Diago
4. Registro y seguimiento de tomas – Andrés
5. Citas médicas, alertas y reportes – Mario
